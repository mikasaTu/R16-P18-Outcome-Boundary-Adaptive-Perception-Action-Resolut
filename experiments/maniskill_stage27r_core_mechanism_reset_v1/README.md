# Stage-2.7R Outcome-Marginal-Value Core-Mechanism Reset

This directory is the only mutable scientific scope for Stage-2.7R. It tests the
CC/FC/CF/FF outcome-marginal-value mechanism with one unified multi-resolution
policy, symmetric eight-step treatments, fresh-reset lockstep branching, real
compute accounting, and source-episode-paired statistics.

The preregistration was frozen before confirmatory output. Every registered
oracle arm is executed even if an upstream gate fails; such failures still cap
the claim tier. Stage-2.7R does not execute a learned router, OOD study, pi0.5,
or real-robot evaluation.
